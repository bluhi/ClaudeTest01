# M3U8 링크 찾기

현재 열려 있는 웹페이지의 HTML 소스를 스캔해서 `.m3u8`이 포함된 줄을 찾아 목록으로 보여주는 Chrome 확장 프로그램입니다. 목록의 각 항목을 클릭하면 해당 URL(또는 전체 줄)이 클립보드에 복사됩니다.

## 설치 방법

1. Chrome 주소창에 `chrome://extensions`를 입력해 이동합니다.
2. 우측 상단의 "개발자 모드"를 켭니다.
3. "압축해제된 확장 프로그램을 로드합니다" 버튼을 클릭합니다.
4. 이 폴더(`m3u8-finder`, `manifest.json`이 있는 위치)를 선택합니다.

## 사용 방법

1. `.m3u8` 링크를 찾고 싶은 페이지를 엽니다.
2. 확장 프로그램 아이콘을 클릭합니다.
3. 팝업에 현재 페이지 소스에서 `.m3u8`이 포함된 줄 목록이 표시됩니다.
4. 항목을 클릭하면 URL(또는 전체 줄)이 클립보드에 복사됩니다.
5. 페이지가 동적으로 바뀐 뒤에는 "다시 스캔" 버튼으로 재스캔할 수 있습니다.

## 동작 방식 / 제한사항

- `chrome.scripting.executeScript`로 활성 탭의 `document.documentElement.outerHTML`을 가져와 줄 단위로 `.m3u8` 포함 여부를 검사합니다.
- 페이지의 **정적 HTML 소스**만 검사하므로, 네트워크 요청(XHR/fetch)으로만 로드되고 DOM/스크립트 소스에 문자열로 남지 않는 `.m3u8` URL은 찾지 못할 수 있습니다.
- `chrome://`, 웹스토어 등 확장 프로그램 실행이 금지된 페이지에서는 스캔할 수 없습니다.
